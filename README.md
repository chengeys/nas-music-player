# 知行音乐 v1

手机网页播放器，直连群晖 NAS 私有曲库（3028 首）。纯静态 PWA，无需安装、免签名。

## 功能

- **推荐**：继续听 / 猜你喜欢（按本机播放记录学偏好）/ 按合集浏览 / 随机
- **搜歌**：毫秒级本地搜索，支持歌名/歌手/合集
- **语音点歌**：点 🎤 说"播放周杰伦晴天"（iOS 用网页语音识别，不好用时自动提示用键盘听写）
- **播放器**：锁屏/耳机线控（Media Session）、后台播放、进度条
- **车载模式**：右上角 🚗，大按钮界面
- **设置**：NAS 地址/账号/密码（只存本机）、连接测试、清除记录

## 部署（两步）

### 1. 反代加 /dav/（宝塔，一次）

把 `nginx-dav.conf` 的内容加到 `nas.yjm.ccwu.cc` 的反代配置里。
`proxy_pass` 的主机照抄现有 DSM 反代那台，只把端口改成 **5006**（WebDAV）。
保存后反代要处于**开启**状态。

### 2. 手机上打开

用 iPhone 自带 Safari 打开本页地址（GitHub Pages），点分享 → **添加到主屏幕**。
首次进 **设置** 页填 NAS 账号密码（ai 账号即可），点"测试连接"，通了就能播。

> 外网访问需要反代开着；在公司/家里局域网可直接用 NAS 内网 IP（把设置里的地址改掉即可）。

## 技术说明

- 曲库目录 baked in（`catalog.js`，2026-10-07 扫描 3028 首）
- 音频走 WebDAV 直连：`fetch` + Basic 认证 → blob → `<audio>`，需反代 CORS 头
- 播放记录/偏好全在 localStorage，不上传
- 语音：`webkitSpeechRecognition`（zh-CN），不支持时降级为键盘听写
